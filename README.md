# RCWD Jersey 2026

หน้าดูออเดอร์เสื้อ หมวก และรายการจัดส่งของราชาวดี (rcwd.leamm.com) สำหรับทีมงาน

- เลือกดู Jersey เขียว / Jersey ขาว / หมวก RCWD / จัดส่ง ค้นหา (รวมเลขออเดอร์ เช่น #12) กรองตามวันที่สั่ง และดาวน์โหลดเป็น Excel
- บนมือถือทุกหมวดเป็นการ์ดทีละรายการ (เสื้อโชว์ชื่อเหนือเลขใหญ่เหมือนหลังเสื้อ) ไม่ต้องเลื่อนตารางไปข้าง
  ช่องค้นหาติดอยู่ด้านบนตอนเลื่อนรายการยาว ๆ ช่วงวันที่กับปุ่มดาวน์โหลดพับไว้ กดเปิดเมื่อต้องใช้
- หมวกนับเป็นใบ (ออเดอร์หนึ่งสั่งได้หลายใบ)
- **แก้ชื่อหลังเสื้อ / เลขหลังเสื้อ** ได้จากหน้าเว็บ: กด "แก้ไข" ที่แถวเสื้อ แก้แล้วกดบันทึก (หรือ Enter; Escape ยกเลิก)
  ต้องมี `Update.gs` ในสคริปต์ของชีต (ดูหัวข้อตั้งค่า) สคริปต์จะแก้เฉพาะ 2 เซลล์ของแถวที่มีเลขออเดอร์ตรงกัน
  และจดค่าเดิมไว้ในแท็บ "แก้ไขจากเว็บ (log)" ทุกครั้ง ไม่ลบอะไรในชีตเลย แถวที่พิมพ์เพิ่มเอง (ไม่มีเลขออเดอร์) แก้ในชีตโดยตรง
- **หน้าเช็กลิสต์แจกของ** (`rcwd.leamm.com/checklist`, ปุ่ม "เช็กลิสต์" ที่หัวหน้าออเดอร์): หนึ่งแถวต่อคนสั่ง รวมทุกชิ้นที่ต้องให้
  (เสื้อแต่ละตัว: สี ไซซ์ ชื่อ เลข และหมวกกี่ใบ) จัดกลุ่มตามชั้น/ห้องของคนสั่ง เรียงเป็นตัวเลข (ม.1/2, ม.1/5, ม.2/5, ม.5/2, ม.6/7
  ไม่ใช่เรียงตามตัวอักษร อ่านได้ทั้ง "ม.4" + "2", "4/2" ที่กรอกรวมมา และเลขไทย) ในกลุ่มเรียงตามชื่อ ออเดอร์ที่เลือกจัดส่งมีป้าย "จัดส่ง"
  ติ๊ก "แจกแล้ว" ครั้งเดียวต่อออเดอร์ สคริปต์บันทึกคอลัมน์ "แจกแล้ว" ของทุกแถวในออเดอร์นั้น (ต้องมีคอลัมน์นั้นและสคริปต์ที่รองรับ
  action `update` ดูหัวข้อตั้งค่า) มีปุ่มซ่อนที่แจกแล้ว ค้นหาตามชื่อ ชั้น/ห้อง ของ หรือ #ออเดอร์ และดาวน์โหลด Excel เป็นตาราง
  หนึ่งแถวต่อคนสั่ง เลือกคอลัมน์ได้ หน้าออเดอร์หลักเรียงตามลำดับในชีตเหมือนเดิม
- **เลือกคอลัมน์ในไฟล์ Excel** ได้ (ติ๊กออกคอลัมน์ที่ไม่ต้องการ และจะเอาแผ่น "สรุป" ด้วยหรือไม่) จำไว้ต่อหมวดในเครื่องนั้น
- หมวด **กำไร** คำนวณรายได้ ต้นทุน กำไร และอัตรากำไรจากรายการที่สลิปผ่านแล้ว (ตามช่วงวันที่ที่เลือก) แบบสด ๆ
  ราคาขายและต้นทุนตั้งต้นตาม "บันทึกข้อความ การจัดทำและจัดจำหน่ายของที่ระลึก คณะราชาวดี 2569"
  (เสื้อ 299 หมวก 279 เสื้อ 2 สี 590 เสื้อ+หมวก 570 ครบเซ็ต 849 · ต้นทุนเสื้อ 240 / 3XL 260 หมวก 220)
  แก้ตัวเลขได้ในแผง "ราคาและต้นทุนที่ใช้คำนวณ" (เพิ่มค่าส่งต่อออเดอร์ ค่าใช้จ่ายอื่น ๆ ได้) แล้วคำนวณใหม่ทันที
  ของในออเดอร์เดียวกัน (เลขออเดอร์เดียวกัน เช่น #9-1, #9-2 และหมวก #9) คิดราคาตามชุดที่ถูกที่สุดก่อน
  (ครบเซ็ต > เสื้อ 2 สี > เสื้อ+หมวก > ชิ้นเดี่ยว) จึงเป็นยอดประมาณการจากรายการ ไม่ใช่ยอดเงินในบัญชี;
  ถ้าสคริปต์ส่งช่อง `amount` (ยอดที่จ่ายจริง) มากับแถว หน้าเว็บจะใช้ยอดนั้นแทนสำหรับออเดอร์นั้น
  ดาวน์โหลด Excel ในหมวดนี้ได้ใบสรุปกำไร 1 ชีต
- **อีเมลสรุปออเดอร์ถึงลูกค้า** (`apps-script/Email.gs`, เมนู RCWD ในชีต): ส่งจาก rcwd.official@gmail.com ผ่าน Gmail ของบัญชี
  เจ้าของสคริปต์ (ไม่ต้องใช้ App Password และได้ SPF/DKIM ของ Gmail จึงไม่ตกสแปม) หนึ่งฉบับต่อออเดอร์ที่สลิปผ่านแล้ว
  มีเลขออเดอร์ รายการทุกชิ้น (สี ไซซ์ ชื่อ เลขหลังเสื้อ หมวกกี่ใบ) ยอดที่ชำระ วิธีรับของหรือที่อยู่จัดส่ง และช่องทางติดต่อ
  ออกแบบเป็นตารางสไตล์ inline อ่านได้ทั้งมือถือและคอม พร้อมข้อความล้วนประกบ ส่งแล้วจดไว้ในแท็บ "อีเมลที่ส่งแล้ว (log)" จึงไม่ส่งซ้ำ
  (ลบแถวในนั้นถ้าจะส่งใหม่) ไม่แก้ข้อมูลออเดอร์ใด ๆ Gmail ธรรมดาส่งได้ราว 100 ฉบับ/วัน สคริปต์หยุดเองเมื่อโควตาหมดและส่งต่อวันถัดไป
- จัดส่ง: ชื่อผู้รับ เบอร์ (กดโทรได้) ที่อยู่ ของที่ต้องใส่กล่อง สถานะส่งแล้ว/รอส่ง เลขพัสดุ และปุ่มคัดลอกชื่อ+ที่อยู่ไปทำใบจ่าหน้า
- ข้อมูลดึงสดจากแท็บ Jersey เขียว / Jersey ขาว / หมวก RCWD / จัดส่ง ใน Google Sheet ผ่าน Apps Script (`doPost`)
  ข้อมูลที่ดึงมาแล้วอยู่ในเครื่องจนกว่าจะกด "ดึงข้อมูลล่าสุด" (ชีตตอบช้า หน้าเว็บจึงไม่ดึงซ้ำเองโดยไม่ได้ขอ) เปิดหน้าใหม่
  สลับไปหน้าเช็กลิสต์ หรือกลับมาเปิดแอปก็เห็นรายการทันที ยังไม่ได้เข้าสู่ระบบจะดูได้อย่างเดียว กด "เข้าสู่ระบบ" เมื่อจะดึงใหม่หรือแก้ไข
  การติ๊กแจกแล้วและการแก้ชื่อ/เลขเห็นผลทันที แล้วส่งให้ชีตเบื้องหลัง (ติ๊กหลายออเดอร์ติด ๆ กันส่งรวมเป็นคำขอเดียว) ถ้าชีตไม่รับจะดีดกลับและบอก
  แถวที่พิมพ์เพิ่มเองในชีตจะขึ้นป้าย "เพิ่มเอง"
- เพิ่มไว้ที่หน้าจอโฮมของ iPhone ได้ (Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม) จะเปิดเต็มจอเหมือนแอป มีโหมดมืดตามเครื่อง
  และตัวหนังสือขยายตามการตั้งค่าขนาดตัวอักษรของเครื่อง (การตั้งค่า > การช่วยการเข้าถึง > จอภาพและขนาดข้อความ)
- ไม่มีข้อมูลลูกค้าหรือรหัสผ่านเก็บไว้ใน repo นี้
- ลิงก์สลิปเปิดใน Google Drive ได้เฉพาะบัญชีเจ้าของฟอร์ม

## ความปลอดภัยและความเป็นส่วนตัว

หน้าเว็บนี้แสดงชื่อ เบอร์ และที่อยู่ของนักเรียนและผู้ปกครอง จึงออกแบบให้ข้อมูลออกจากเครื่องของทีมงานน้อยที่สุด

- **รหัสผ่านไม่ถูกเก็บในเบราว์เซอร์** หน้าเว็บส่งรหัสผ่านครั้งเดียวตอนเข้าสู่ระบบ แล้วเก็บแค่ "โทเค็น" ที่สคริปต์ออกให้ (หมดอายุใน 12 ชั่วโมง)
  ในแท็บ Safari โทเค็นหายไปพร้อมแท็บ (`sessionStorage`) ส่วนแอปที่เพิ่มไว้ที่หน้าจอโฮมไม่มีแท็บให้ปิด จึงเก็บไว้จนหมดอายุหรือกดออกจากระบบ (`localStorage`)
  กด "ออกจากระบบ" แล้วสคริปต์จะไม่รับโทเค็นนั้นอีก และหน้าเว็บล้างข้อมูลที่แสดงอยู่ทั้งหมด
- **ไม่โหลดอะไรจากเว็บอื่น** ฟอนต์ (Prompt, Teko) อยู่ในโฟลเดอร์ `fonts/` ของเว็บเอง ไฟล์ Excel สร้างด้วย `xlsx-lite.js` ในเว็บ
  (เดิมโหลด SheetJS 900 KB จาก CDN ตอนกดดาวน์โหลด) จึงไม่มีบุคคลที่สามเห็นว่าใครเปิดหน้านี้ และ Content-Security-Policy ใน `index.html`
  อนุญาตเฉพาะไฟล์ของเว็บเองกับการเรียก Apps Script (`script.google.com` และ `script.googleusercontent.com`) เท่านั้น
- ฟอร์มเข้าสู่ระบบส่งแบบธรรมดาไม่ได้ (`form-action 'none'`) ถ้า JavaScript โหลดไม่ขึ้น รหัสผ่านจะไม่หลุดไปอยู่ใน URL
  หน้าเว็บไม่ทำงานถ้าถูกฝังในเว็บอื่น ไม่ส่ง Referer ออกไปที่ลิงก์ภายนอก และบอกเสิร์ชเอนจินไม่ให้เก็บ (`noindex`)
- **ใน Apps Script** (ชุด `apps-script/Auth.gs`): รหัสผ่านเก็บเป็น salted hash ใน Script Properties ไม่อยู่ในโค้ด,
  ใส่รหัสผิด 5 ครั้ง/15 นาที ต่อชื่อผู้ใช้จะถูกพักชั่วคราว และถ้าผิดรวมทุกคน 50 ครั้ง/10 นาที ระบบพักรับการเข้าสู่ระบบชั่วคราว,
  เทียบรหัสและลายเซ็นโทเค็นแบบเวลาคงที่
- สิ่งที่หน้าเว็บเก็บในเบราว์เซอร์: `rcwd-session` (โทเค็นกับชื่อผู้ใช้ ตามข้างบน), `rcwd-cache` (ข้อมูลชุดล่าสุดที่ดึงมา
  ในแท็บ Safari อยู่กับแท็บ ในแอปหน้าจอโฮมอยู่ในเครื่อง หมดอายุใน 12 ชั่วโมง และถูกลบตอนกดออกจากระบบ
  ทำให้เปิดหน้าแล้วเห็นรายการทันทีโดยไม่ต้องรอชีต; ไม่มีรหัสผ่านหรือโทเค็นอยู่ในนั้น), `rcwd-ui` (หมวดที่เปิดล่าสุด)
  `rcwd-ui-checklist` (หมวดกับตัวเลือกซ่อนที่แจกแล้วของหน้าเช็กลิสต์), `rcwd-pricing` (ราคากับต้นทุนที่แก้ในแผงกำไร)
  และ `rcwd-export` (คอลัมน์ที่ติ๊กออกจากไฟล์ Excel) นอกจากอันแรกไม่มีข้อมูลส่วนบุคคล

สิ่งที่ยังต้องระวัง (ตั้งใจเขียนไว้ตรง ๆ):

- ลิงก์ Web app ของ Apps Script เป็นสาธารณะและต้อง deploy แบบ "Anyone" ใครก็ส่งคำขอได้ ความปลอดภัยจึงอยู่ที่รหัสผ่านที่ยาวและไม่ซ้ำกับที่อื่น
  (ตั้งอย่างน้อย 12 ตัวอักษร) การพักรับคำขอทั้งระบบทำให้คนที่ยิงคำขอผิด ๆ รัว ๆ ทำให้ทีมงานเข้าไม่ได้ชั่วคราวได้ (Apps Script ไม่เห็น IP ของผู้เรียก)
- ไฟล์ Excel ที่ดาวน์โหลดมีชื่อ เบอร์ ที่อยู่ครบ ใช้เสร็จแล้วลบออกจากเครื่องและจาก iCloud Drive / Downloads ด้วย
- ถ้ายังใช้สคริปต์เวอร์ชันเก่า (ไม่มี Auth.gs) หน้าเว็บจะเก็บรหัสผ่านไว้ในหน่วยความจำของหน้านั้นเท่านั้น ปิดหรือรีเฟรชแล้วต้องเข้าสู่ระบบใหม่
  (หน้าเว็บบอกไว้ที่ท้ายหน้า) อัปเดตสคริปต์ตามขั้นตอนด้านล่างเพื่อให้จำการเข้าสู่ระบบได้
- เข้าใช้ผ่าน rcwd.leamm.com เท่านั้น หน้าปลอมที่ก๊อปไปวางที่อื่นก็ส่งรหัสผ่านไปหาสคริปต์จริงได้ อย่ากรอกรหัสในลิงก์ที่ไม่ใช่โดเมนนี้
- ใช้คอมพิวเตอร์ร่วมกับคนอื่นให้กด "ออกจากระบบ" ทุกครั้ง หมดฤดูกาลแล้วค่อยจำกัดการแชร์ชีตให้เหลือเฉพาะคนที่ยังต้องใช้ (ข้อมูลในชีตไม่ถูกแก้หรือลบโดยหน้าเว็บหรือสคริปต์ชุดนี้)

## ตั้งค่า

1. ใน Apps Script ของชีตคำตอบ: เพิ่มไฟล์ใหม่ชื่อ `Auth` แล้ววางเนื้อหาจาก `apps-script/Auth.gs` ทั้งไฟล์
   แก้ `doPost` เดิมตามตัวอย่างใน `apps-script/Code.gs.sample` (เรียก `Auth.handle(e)` แทนการเช็กรหัสผ่านเอง และส่ง `token`/`expiresAt` กลับไปพร้อมข้อมูล)
   แล้วลบรหัสผ่านที่เคยเขียนไว้ในโค้ดออก
2. ตั้งรหัสผ่านครั้งแรก: แก้ชื่อผู้ใช้กับรหัสผ่านใน `SETUP_setPassword` (ท้ายไฟล์ Auth) เลือกฟังก์ชันนี้แล้วกด "เรียกใช้" ครั้งเดียว
   (ครั้งแรก Google จะถามสิทธิ์) เสร็จแล้วลบรหัสผ่านออกจากโค้ด ทำซ้ำได้เมื่ออยากเปลี่ยนรหัสหรือเพิ่มคน
3. Deploy > New deployment > Web app (Execute as: Me, Who has access: Anyone) แล้วก๊อปลิงก์ที่ลงท้าย `/exec` ใส่ใน `config.js`
   (สคริปต์ที่เคย deploy แล้ว: Deploy > Manage deployments > Edit > Version: New version ลิงก์เดิมใช้ต่อได้)
4. (ถ้าอยากแก้ชื่อ/เลขหลังเสื้อจากหน้าเว็บ) เพิ่มไฟล์ชื่อ `Update` วางเนื้อหาจาก `apps-script/Update.gs` ทั้งไฟล์
   ปรับ `CONFIG` ต้นไฟล์ให้ตรงกับชื่อแท็บเสื้อและหัวคอลัมน์ในชีต (ออเดอร์ / ชื่อหลังเสื้อ / เลขหลังเสื้อ)
   แล้วใน `doPost` เพิ่มบรรทัด `if (auth.action === 'update') return Auth.json(RCWD_UPDATE.handle(auth.body, auth.username));`
   (สคริปต์รุ่นเก่าที่ยังไม่มี Auth.gs: หลังเช็กรหัสผ่านผ่านแล้ว ใส่ตามคอมเมนต์หัวไฟล์ Update.gs) แล้ว deploy เวอร์ชันใหม่
   ถ้ายังไม่ใส่ หน้าเว็บจะบอกว่า "สคริปต์ของชีตยังไม่รองรับการแก้ไข" ตอนกดบันทึก ส่วนอื่นใช้ได้ตามปกติ
   หน้าเช็กลิสต์ใช้ action เดียวกัน (`given: true/false`) และต้องมีคอลัมน์หัวว่า "แจกแล้ว" ในแท็บเสื้อและแท็บหมวก
   (สร้างคอลัมน์เองได้ในชีต ชื่อหัวต้องตรง) ส่วนชั้น/ห้องของเสื้อ สคริปต์ส่งมาในช่อง `buyer`, `grade`, `room` ของแถวเสื้อ
5. (ถ้าอยากส่งอีเมลสรุปออเดอร์) เพิ่มไฟล์ชื่อ `Email` วางเนื้อหาจาก `apps-script/Email.gs` ทั้งไฟล์ ปรับข้อความใน `RCWD_EMAIL`
   (ที่รับของ ช่องทางติดต่อ) เพิ่มสองบรรทัดเมนูใน `onOpen` ตามคอมเมนต์หัวไฟล์ แล้วรัน `sendTestOrderEmail` ครั้งแรกเพื่อให้สิทธิ์ Gmail
   และดูตัวอย่างในกล่องจดหมายตัวเอง สคริปต์ต้องอยู่ในบัญชี rcwd.official@gmail.com (หรือตั้ง "ส่งอีเมลในชื่อ" แล้วใส่ใน `from`)
   ฟอร์มต้องเก็บอีเมลลูกค้า (ตั้งค่าฟอร์ม > เก็บที่อยู่อีเมล) หรือมีคำถามที่ชื่อมีคำว่า "อีเมล"
6. DNS ของ leamm.com: เพิ่ม CNAME record `rcwd` ชี้ไปที่ `xbaconyt-lab.github.io`
7. ใน GitHub > Settings > Pages ติ๊ก **Enforce HTTPS** (หน้าเว็บพาไป https เองด้วยถ้าเปิดมาแบบ http)

แก้โค้ด Apps Script แล้วต้อง Deploy > Manage deployments > Edit > Version: New version เว็บถึงจะใช้โค้ดใหม่
หน้าเว็บเวอร์ชันนี้ใช้กับสคริปต์เวอร์ชันเก่าได้ (แค่ไม่จำการเข้าสู่ระบบ) และหน้าเว็บเวอร์ชันเก่าก็ยังเข้าสคริปต์ที่ใส่ Auth.gs แล้วได้
